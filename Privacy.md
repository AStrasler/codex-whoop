# Codex WHOOP — Privacy Statement

Last updated: September 25, 2026

Codex WHOOP is a personal integration operated by Aaron Strasler to access and analyze the operator's own WHOOP data using Codex. It is not a public service and does not offer access to other users.

## Data accessed and purpose

With the account owner's authorization, the integration reads WHOOP recovery, sleep, physiological cycles and strain, workouts, profile information, and body measurements. This information is used to answer the owner's questions and produce requested summaries and analyses. The integration uses read-only access to WHOOP records.

## Processing and sharing

The WHOOP connection runs on the owner's computer. Data returned to Codex is shared with OpenAI for processing under the owner's OpenAI account settings and applicable OpenAI terms and privacy policy: https://openai.com/policies/privacy-policy/. Local execution of the connector does not mean that AI processing happens only on the computer.

The operator does not sell WHOOP data or use this integration for advertising. GitHub hosts this privacy statement; WHOOP records, credentials, and access tokens are not intended to be published there.

## Credentials, retention, and deletion

The connector stores application credentials and authorization tokens locally so it can access WHOOP and refresh authorization. The owner can revoke the integration's access through WHOOP and delete its local credentials and tokens. Revocation stops future authorized access; it does not automatically delete information already included in Codex conversations or exported files.

Data included in conversations is retained according to the owner's OpenAI settings and applicable policies. Locally saved reports remain until the owner deletes them. The owner can manage or delete conversations using the controls available in their OpenAI account.

For privacy questions, contact Aaron Strasler at the Contact email specified in the WHOOP developer application.

## Changes

This statement will be updated if the integration's data handling changes.
